# LushSecret - E-commerce de Lencería y Juguetes

## 🌟 Características

- 🛍️ E-commerce completo con carrito de compras
- 💳 Integración con Bold para pagos
- 📦 Sistema de tracking de envíos automático
- 📊 Panel de analytics y estadísticas en tiempo real
- 👤 Sistema de autenticación de usuarios y admin
- 🎨 Diseño luxury gold rose elegante y moderno
- 📱 Responsive design

## 🚀 Tecnologías

### Frontend
- Next.js 14
- React 18
- TailwindCSS
- Recharts para gráficos
- React Icons

### Backend
- Node.js
- Express
- PostgreSQL
- JWT para autenticación
- Nodemailer para emails
- Node-cron para tareas automáticas

## 📦 Instalación

### Frontend
```bash
cd frontend
npm install
npm run dev
```

### Backend
```bash
cd backend
npm install
npm start
```

## 🔧 Variables de Entorno

### Backend (.env)
```
DATABASE_URL=your_postgresql_connection_string
PORT=4000
JWT_SECRET=your_jwt_secret
EMAIL_USER=your_email
EMAIL_PASS=your_email_password
```

### Frontend (.env.local)
```
NEXT_PUBLIC_API_URL=http://localhost:4000
```

## 🌐 Despliegue en Vercel

1. Conecta tu repositorio de GitHub con Vercel
2. Configura las variables de entorno en Vercel
3. Despliega automáticamente

### Para Clientes
- Navegación por categorías
